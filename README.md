# NEON BREACH

A small top-down arena shooter built with Canvas, JavaScript, and Vite.

## Run it

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Controls

- Move with `WASD` or the arrow keys.
- Aim with the mouse and hold the left mouse button to fire.
- On touch screens, drag the left side of the arena to move and the right side to aim and fire.
- Press `Space` to reload.
- Press `Esc` to pause; press `R` after a run ends to restart.

Survive pursuing hostiles, use cover, and push through increasingly difficult waves. Your best score is saved in this browser.
